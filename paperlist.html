1 如何维护这个列表

每篇文献是一条 BibTeX 记录,都存在 refs.bib 里:

  • 新增:往 refs.bib 粘贴一条 BibTeX 条目(谷歌学术或 arXiv 都能导出);
  • 分类:给条目写 keywords,可多个——同一篇论文会自动出现在所有对应分类下;
  • 引用:正文写 \parencite{yao2023react},渲染成 “[3]” 这样的编号,点击跳到文末对应条目;
  • 发布:git push 后 GitHub Actions 自动构建部署,不需要本地编译; 本地预览则运行 ./build.sh,打开 docs/paperlist.html。
